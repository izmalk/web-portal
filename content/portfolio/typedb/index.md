## Documentation for database developers

I joined Vaticle, now TypeDB, in November 2022 as its first documentation specialist. Working with the engineering team, I documented TypeDB's open-source, enterprise, and cloud products.

My work covered installation guides, quick starts, developer guides, tutorials, and API references: the material developers need to get started, build an application, and find technical details as they work.

## Connect writing with engineering

Alongside the documentation itself, I collaborated with engineers on CI/CD automation, documentation tests, and API reference generation. These workflows connect the written guidance with the product and make documentation part of the development process.

## Read the historical documentation

The [documentation snapshot from 15 June 2024](https://web.archive.org/web/20240615140608mp_/https://typedb.com/docs/home/overview) preserves the documentation from that period. It is an archived documentation set; the current TypeDB product and documentation have continued to evolve.
