## From a data model to a working application

Tarantool Data Grid stores complex business objects and supports real-time queries across them. Its documentation connects the developer's view of a domain model with the operator's view of a running cluster.

I worked as a Senior Technical Writer on the Tarantool team, writing documentation in English and translating it into Russian. This entry presents samples from the Russian-language Tarantool Data Grid 1.0 documentation, dated 2 November 2020.

## Support developers and operators

The documentation set includes an application development guide, an operations guide, and reference material for requests from external systems. Developers can work through domain modelling, execution environments, repository APIs, and testing. Operators can find installation, cluster configuration, security, logging, metrics, and administration guidance.

The samples show two ways to explain the product: an annotated interface helps readers recognise navigation and cluster controls, while a schema example makes the domain-model concepts concrete.

## The historical samples and today's documentation

The gallery shows selected pages from the 2020 release 1.0 documentation. The [current Tarantool Data Grid documentation](https://www.tarantool.io/docs/tdg) covers a substantially newer version and has evolved since my work on the product.
