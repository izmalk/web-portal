## A theme for technical documentation

Ulwazi brings the Vanilla Framework's visual language to Sphinx documentation. Built on sphinx-basic-ng, it connects an established documentation generator with the design framework used across Canonical's web presence.

I'm the project's main maintainer and author. The work brings together documentation engineering and interface design: the structure of a page, the navigation around it, and the tools authors use to build and preview their documentation.

## Design and development together

A documentation theme shapes how readers move between topics and find their place within a page. Ulwazi combines templates, styles, and navigation behavior into a reusable package, with configuration for a generic Vanilla appearance and Canonical-specific needs.

The project includes sample documentation and a local preview workflow. Changes to content, templates, and styles can be reviewed together, making the documentation site part of the development process.

## Explore the work

The [published documentation](https://documentation.ubuntu.com/ulwazi/) serves as both a guide and a working demonstration. It includes installation instructions, configuration reference, and contributor guidance. The [source repository](https://github.com/canonical/ulwazi) contains the theme, tests, and sample documentation.

Ulwazi is an example of the work I enjoy most: improving a reader's experience while making the underlying system easier for documentation teams to use and maintain.
