## Documentation for search infrastructure

Charmed OpenSearch uses a Juju operator to manage OpenSearch clusters. The documentation takes readers from their first deployment to practical tasks such as enabling encryption, scaling a cluster, managing backups, and monitoring performance.

As a Technical Author in Canonical's Data Platform team, I work on documentation for Charmed OpenSearch alongside other data products.

## Support learning and daily operations

The documentation follows Diátaxis. A tutorial introduces deployment and client connections; how-to guides cover operational tasks; reference pages provide requirements and release details; explanation pages describe security, monitoring, and cluster behaviour.

That structure gives a new user a guided route into the product while helping an administrator find a procedure or understand a design choice.
