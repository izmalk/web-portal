The docs-as-code approach brings documentation into the software development workflow. Three widely used lightweight markup languages are Markdown, reStructuredText and AsciiDoc. Each has strengths suited to different documentation needs.

- **Markdown** is known for its simplicity and widespread adoption, from GitHub repositories to blogging platforms. Its straightforward syntax makes source files easy to read and edit.

- **reStructuredText** (reST) is well established in the Python community. Its support for detailed structure and cross-references makes it useful for complex technical documentation. Combined with Sphinx, it can produce well-organised documentation websites.

- **AsciiDoc** offers a broad range of features for structured documentation. It is particularly useful when the same source needs to produce several output formats, such as HTML, PDF and EPUB.

These languages work well with version control, continuous integration and automated testing. Combined with shared review practices, they help writers and developers keep documentation aligned with product changes and user needs.
